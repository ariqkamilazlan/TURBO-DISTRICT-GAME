# TURBO DISTRICT - DAM50403 Final Project

Open `index.html` in a browser, or in VS Code use the Live Server extension.

Replace-me spots (search for `REPLACE` in the HTML files):
- images/hero/hero-car.svg, cars/car-1..8, world/*, gallery/* : your own images
- gallery.html : change RUQekDcYSCI to your YouTube video ID
- contact.html : social links (href="#"), studio email and phone

Hosting (Netlify): go to app.netlify.com/drop and drag the whole `TURBO-DISTRICT` folder in. Copy the live URL.
